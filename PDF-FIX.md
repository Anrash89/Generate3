# Исправление PDF и печати — 02.11.2026

## Как обновить GitHub Pages

1. Распакуйте архив. Откройте папку `Generate3-main`.
2. Загрузите **содержимое этой папки** в корень репозитория `Generate3`, заменив одноимённые файлы. Саму папку `Generate3-main` внутрь репозитория добавлять не нужно.
3. Обязательно загрузите новую папку `export` целиком и файл `site-assets/static/chunks/label-studio-pdf-v1.js`. Одного `index.html` недостаточно.
4. Сделайте Commit changes и дождитесь обновления GitHub Pages. В браузере обновите страницу с очисткой кэша: Ctrl+F5 на Windows или Cmd+Shift+R на Mac.

Сборка, Node.js, сервер и ключи API для работы сайта не нужны. Публикация остаётся обычной статической GitHub Pages. Для проверки на компьютере используйте локальный HTTP-сервер, например `python3 -m http.server 8000`, затем откройте `http://localhost:8000`. Не запускайте `index.html` через `file://`: браузер блокирует загрузку шрифтов и модулей экспорта.

## Как пользоваться

- **Скачать PDF** — сразу скачивает готовый файл. Размер страницы равен размеру этикетки в миллиметрах. Одна этикетка — одна страница. Текст и полосы штрихкода векторные, шрифты встроены. PDF можно передать в типографию или поместить в макет коробки с сохранением чёткости текста и штрихкода.
- **Печать** под предпросмотром — отдельный системный диалог для принтера. Выберите соответствующий размер бумаги, масштаб 100% / «Фактический размер», поля 0, отключите колонтитулы. Возможность печати до края зависит от принтера. Ctrl+P тоже выводит только этикетку.
- **PNG** — запасной вариант: 600 DPI, с метаданными разрешения. Для 100×100 мм получается 2362×2362 пикселя. Разметка безопасной зоны в экспорт не попадает.
- Если текст или знаки не помещаются, выгрузка остановится с пояснением. Увеличьте размер этикетки, сократите текст или уменьшите шрифт / знаки. Это предотвращает незаметное обрезание данных.

Знаки маркировки из исходных PNG встроены в исходном разрешении; текст, штрихкод, рамка и знак II класса защиты — векторные. Перерисовка растровых знаков не выполнялась.

## Что исправлено

- PDF больше не зависит от браузерной пагинации, масштаба предпросмотра и положения прокрутки.
- Печатная копия создаётся отдельно от интерфейса и масштабированных контейнеров. Интерфейс полностью исключён из потока печати, поэтому не создаёт лишние страницы.
- Удалён преждевременный таймер очистки печати. Копия удаляется после закрытия диалога.
- Исправлена проверка переполнения внутреннего текстового блока и пересчёт после загрузки шрифтов.
- В штрихкод добавлены боковые белые поля. SVG переносится в PDF в виде отдельных векторных полос, без скриншота.
- Исправлена найденная ошибка кнопки «Новая»: обращение к отсутствующей функции очистки поиска.
- Сохранены прежние ключи черновиков и библиотеки, JSON-импорт и экспорт, электрические характеристики и знаки маркировки.

## Проверка сборки

Проверено автоматизированно в Chromium:

- 100×100 мм с длинными русскими текстами; 58×40, 40×58 и 70×50 мм.
- Один лист PDF; точные размеры страницы в скачиваемом PDF; встроенные шрифты.
- EAN-13 `7683344010428` и CODE128 `ABC-123456` прочитаны программным декодером из отрисованных PDF.
- Изменение масштаба предпросмотра и включение безопасной зоны не меняют изображение PDF.
- Системная печать, повторная печать после закрытия диалога и Ctrl+P дают по одной странице.
- PNG для 100×100 мм: 2362×2362 пикселя, 600 DPI; штрихкод читается декодером.
- При переполнении выгрузка блокируется.

Физическая печать и сканирование реальным сканером не выполнялись. Перед тиражом распечатайте один экземпляр на используемом принтере и проверьте размеры и считывание.
