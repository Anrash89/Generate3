# Конструктор этикеток

Готовый статический сервис для GitHub Pages. Установка зависимостей и сборка не нужны.

## Обновление

1. Распакуйте архив.
2. Загрузите всё содержимое папки Generate3-main в корень прежнего репозитория с заменой файлов: index.html, icons, site-assets и остальные файлы.
3. Сохраните изменения (Commit changes). Если GitHub Pages уже настроен, дождитесь обновления сайта.
4. Если отображается прежняя версия, нажмите Ctrl+F5.

Для первого запуска Pages: Settings → Pages → Deploy from a branch → main → / (root) → Save.

## Добавлено

- Знак «II класс защиты»: два вложенных квадрата. Выбирается в разделе «Знаки и маркировка» и попадает в предпросмотр, PNG и печать/PDF.
- Поля «Напряжение, В», «Частота тока, Гц», «Мощность, Вт» в разделе «Состав и характеристики». Введите число или диапазон; на этикетке автоматически появятся русские единицы. Пустые поля не выводятся.
- Новые поля и знак сохраняются в черновиках и шаблонах, а также в JSON-экспорте.
